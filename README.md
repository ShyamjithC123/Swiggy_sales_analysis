# 🍔 Swiggy Sales Analysis – Excel Dashboard

## 📊 Project Overview

This project analyzes **Swiggy food-ordering data using Microsoft Excel** to identify sales trends, customer ratings, order performance, and key business insights.

An interactive Excel dashboard was created using **Pivot Tables, Pivot Charts, KPIs, filters/slicers, and data analysis techniques**.

## 🎯 Objectives

* Analyze overall Swiggy sales performance
* Track total sales and total orders
* Analyze monthly sales trends
* Evaluate average customer ratings
* Understand rating volumes
* Calculate Average Order Value (AOV)
* Identify patterns across food categories, locations, restaurants, and dishes

## 🗂️ Dataset

The dataset contains Swiggy order-related information, including:

* State
* City
* Order Date
* Day
* Quarter
* Week
* Restaurant Name
* Location
* Category
* Dish Name
* Food Type
* Price (INR)
* Rating
* Rating Count
